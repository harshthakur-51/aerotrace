# Version 2 prospective replication plan

This plan binds two fresh FlightGear process launches and six episodes to the
version 2 temporal prediction method before collection. The first group requests
8,000 feet and 240 knots. The second requests 6,000 feet and 230 knots. Each
group collects reference, isolated pressure supply and generator plus pressure
supply in that order. Each episode must pass the unchanged fresh admission guard
using its declared altitude and speed targets. Exact native windows are recorded
in the case options.

Each target describes an expected candidate set inside the finite catalogue.
The joint target requires both independent and grouped configurations. A score
is calculated after public-only prediction. The sealed development registry
includes the prior pilot, both new development contrasts and the two synthetic
quantity variants. The legacy schema-invalid connection probe remains excluded.

Record setup and collection failures, insufficient observations and mismatches.
Count two planned simulator flight groups separately from six episodes and
their correlated observations. Both groups use the same aircraft model, airport
and fixed weather setup. The operating condition and process restart provide
replication within that environment.
